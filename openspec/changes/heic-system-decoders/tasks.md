# Tasks

Platform notes: tests marked **[macOS]** must pass on the macos-14 runner, **[Linux-real]** on the ubuntu-24.04 runner
with `libheif1 libheif-plugin-libde265` installed, **[Windows-skip]** run on windows-2022 and skip with a printed
reason when the HEIF/HEVC extensions are absent. `PHOTOSQUIRREL_REQUIRE_SYSTEM_HEIF=1` (Linux and macOS jobs) turns a
skip into a failure. Everything else runs on every runner with the fake decoder registry.

Implementation notes: the macOS backend declares the few CoreFoundation, CoreGraphics and ImageIO C functions it uses itself instead of using `objc2-core-foundation`/`objc2-core-graphics` (plain C ABI, compile-checked for `aarch64-apple-darwin` with a stand-in crate); the WIC backend loads Media Foundation's `MFTEnumEx` at run time so an N edition without `mfplat.dll` still starts (compile-checked for `x86_64-pc-windows-msvc`).
